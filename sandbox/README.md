# Локальная песочница

Проверка приложения через настоящий SDK с имитацией камер, оплаты, печати и сервера панели администратора.

Нужен **Node.js 24+**. Из корня скачанного репозитория выполните:

```sh
node sandbox/start.mjs
```

Откройте адрес из терминала: по умолчанию <http://127.0.0.1:4174>. Устанавливать npm-зависимости, Python или Electron не требуется. Также доступна команда `npm start`. Остановка — Ctrl+C.

Подробная инструкция и сценарии: [документация песочницы](../docs/SANDBOX.md).
