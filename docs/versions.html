Версии и совместимость#

Компонент Версия контракта
API внешних приложений 1
Манифест schema_version: 1
Совместимость SDK в манифесте sdk: "1"
Пакет @pbt/sdk 0.1.0

На фотобудке должна быть установлена программа с поддержкой описанных методов SDK. В неё входят окно запуска внешних приложений и локальный сервер, который управляет оборудованием. Контракт соответствует проверенной версии программы фотобудки 0.2.38; разные сборки с одинаковым номером могут включать разные дополнения, поэтому совместимость конкретной фотобудки проверяет её администратор.

Форматы данных#

API.md описывает методы, ошибки, единицы денег и правила повторов. openapi.json содержит маршруты и типы API внешних приложений; service.schema.json — манифест. Готовый SDK поставляется вместе с TypeScript-декларациями.

Контрольные суммы файлов и версии находятся в compatibility.json. Обычному приложению не нужно читать этот файл во время работы: он помогает сверить комплект при передаче и разборе несовместимости.

Обновление приложения#

При обновлении SDK пересоберите сайт, повысьте версию в service.json и передайте новый ZIP администратору фотобудки. Не заменяйте байты уже опубликованной версии. Пакет внешнего приложения не обновляет программу фотобудки и её локальный сервер.

После обновления снова проверьте свою последовательность оплаты, съёмки, печати и цифровой выдачи. Суммы API внешних приложений — рубли. Для повторов сохраняйте идентификаторы операций; не воспроизводите денежные или физические команды автоматически после перезапуска.
