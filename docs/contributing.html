Работа с документацией и SDK#

Документация хранится в Markdown; HTML, навигация и индекс поиска строятся из тех же файлов. Для изменений достаточно Node.js 24+ и npm. Внутренний репозиторий терминала, Python и Electron не нужны.

Изменение текста#

  1. Отредактируйте нужный docs/*.md.
  2. Выполните npm run docs:build.
  3. Выполните npm run check.
  4. Откройте docs/index.html или запустите npm run docs:serve.
  5. Сохраните Markdown вместе с полученными HTML и поисковым индексом.

Для таблиц, кода и ссылок используется GitHub-flavored Markdown. Относительные ссылки на страницы .md в HTML автоматически превращаются в ссылки на соответствующие .html. Ссылки на JSON, исходники и загрузки сохраняются. HTML работает при открытии из файла и при публикации в подпапке GitHub Pages; внешних CDN и шрифтов нет.

Изменение SDK#

sdk/src/external.ts содержит клиент, sdk/src/types.ts — публичные алиасы, sdk/src/generated.d.ts — типы из OpenAPI. Не меняйте generated.d.ts вручную. Изменение поведения требует согласованного обновления спецификации и фиксации совместимости.

npm run build
npm run check
npm test

Обычная сборка не обновляет контрольные суммы контракта. Если проверка сообщает о несовпадении, сначала разберите изменение и подтвердите совместимость с платформой.

GitHub Pages#

В Settings → Pages выберите источник GitHub Actions. Workflow собирает и проверяет документацию, затем публикует docs/. Проверки pull request не выполняют публикацию. Опубликованный адрес возвращает GitHub; относительные ссылки не требуют ручной правки под имя репозитория.
