# Разработка приложений фотобудки

Собственный интерфейс, камеры, оплата, печать и цифровая выдача — через ограниченный API текущей сессии.

Это публичная документация для автора внешнего приложения. Приложение поставляется как статический сайт в ZIP с `service.json`, запускается в изолированной оболочке и использует браузерный `ExternalClient`.

## Состояние проекта

Завершён первый этап: контракт SDK. В справочнике описаны 30 публичных элементов клиента и 8 низкоуровневых action; OpenAPI содержит 17 runtime-маршрутов. Совместимый локальный кандидат терминала — 0.2.38, SDK — 0.1.0, протокол — 1.

Следующий этап — самостоятельная песочница, работающая без центра, оборудования, токенов и Python-backend. Затем — единое демонстрационное приложение «Фотооткрытка». Эти возможности пока не входят в готовую часть репозитория.

## Основные правила

- Деньги в SDK задаются в рублях: `235.67` — это 235 ₽ 67 коп.
- Таймаут ожидания не отменяет оплату или печать.
- Для повтора неизвестного результата сохраняйте `requestId` и аргументы.
- Принятая команда не подтверждает списание, выдачу всех листов или возврат банком.
- При системной паузе приостановите ввод, отсчёт и превью; после stop освободите ресурсы.
