# Пакет приложения

Платформа принимает ZIP с готовым статическим сайтом. В корне архива находятся `service.json`, entry-файл и необходимые ассеты. Дополнительная верхняя папка проекта не нужна.

## Манифест

```json
{
  "schema_version": 1,
  "id": "example.postcard",
  "version": "1.0.0",
  "name": "Фотооткрытка",
  "entry": "index.html",
  "sdk": "1",
  "capabilities": ["capture:main", "payment", "print", "result:write", "config:read"],
  "requires_online": false,
  "network": { "allowed_origins": [] }
}
```

Полные ограничения полей: [service.schema.json](service.schema.json). ID содержит 2..4 сегмента, разделённых точкой; каждый начинается с латинской строчной буквы. Версия — `MAJOR.MINOR.PATCH` без prerelease. При изменении готовых файлов или SDK повышайте версию: опубликованный пакет неизменяем.

## Разрешения

| Разрешение | Доступ |
|---|---|
| capture:main | Главная камера |
| capture:secondary | Назначенные ракурсы top/side |
| payment | Оплата, продление ожидания наличных, запрос проверки возврата |
| print | Печать своих фотографий |
| result:write | Загрузка обработанных JPEG и цифровая выдача |
| config:read | Публичные настройки, рамки и эффекты |

Действуют только права, одновременно объявленные приложением и разрешённые в настройках услуги в панели администратора. Манифест не открывает внутренний API фотобудки или чужие сессии.

## Файлы и сеть

Используйте относительные ссылки на ассеты: `./assets/app.js`, `./style.css`. Файлы `.env`, ключи, `node_modules`, dev-server, исполняемые файлы и нативные SDK не должны входить в ZIP.

Для внешнего API объявите точный origin:

```json
{ "network": { "allowed_origins": ["https://api.example.com"] } }
```

Пути, query, credentials и маски запрещены. WebSocket-origin указывается отдельно от HTTP. CORS и TLS продолжают действовать. Пустой список разрешает ресурсы своего сайта и локальный SDK, без произвольной внешней сети.

Максимумы пакета: 4096 файлов, 32 MiB на файл, 512 MiB распакованного объёма, 256 MiB архива. Символические ссылки, обход каталогов и неподдерживаемые типы файлов отклоняются.

## Подключение через панель администратора

Передайте администратору фотобудки ZIP, ID и версию приложения, нужные разрешения, способ предоставления результата и описание сценария. В панели администратора — веб-интерфейсе централизованного управления фотобудками — пакет подключается к услуге типа «Внешнее приложение» на тестовой фотобудке. Цена услуги, цена дополнительного листа, публичные настройки `config` и способ предоставления результата задаются в панели администратора.

Перед использованием посетителями проверьте приложение на тестовой фотобудке: подтверждение оплаты, ориентацию и обработку фото, фактическую выдачу листов, QR и результат сессии в панели администратора. При сбое сохраните runId/sessionId, шаг и текст ошибки; не включайте секреты и фотографии посетителя в диагностические сообщения.
