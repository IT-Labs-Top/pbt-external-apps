Совместимость#

Этот репозиторий содержит публичный контракт external-sdk-1 и SDK @pbt/sdk/external версии 0.1.0. Совместимый локальный кандидат терминала, backend и оболочки — 0.2.38; версия протокола — 1; манифест: schema_version=1, sdk="1".

Статус local-candidate означает проверенную локальную связку. Он не подтверждает выкладку на все точки, приёмку физического оборудования или проверку реального центра. Номер 0.2.38 сам по себе недостаточен для идентификации сборки; контрольные суммы и сигнатуры находятся в compatibility.json.

Один контракт, несколько представлений#

Файл Назначение
API.md Нормативное описание поведения и ошибок SDK
openapi.json 17 публичных runtime-маршрутов и типы их данных
service.schema.json JSON Schema манифеста приложения
compatibility.json Зафиксированные версии, сигнатуры и SHA256 публичных артефактов
sdk/src/external.ts Реализация SDK
sdk/src/generated.d.ts Типы, полученные из публичного OpenAPI
sdk/dist Готовый ESM-клиент и декларации

Сборка публичного SDK использует локальные публичные типы. Исполняемая логика соответствует зафиксированному SDK терминала; заменён только путь импорта типов. В репозитории нет backend, его тестовых модулей, учётных данных центра или конфигураций устройств.

Проверки#

npm ci
npm run build
npm run check
npm test

Проверяются декларации SDK, контрольные суммы, все ссылки HTML, якоря, наличие документации публичных методов, отсутствие зависимостей от внутреннего репозитория и базовые правила повторов SDK. Генерация HTML детерминирована; CI обнаруживает несохранённое изменение сгенерированных файлов.

Исходный контракт до переноса прошёл 77 тестов SDK/оболочки и 171 тест backend; один тест символических ссылок Windows был пропущен из-за прав окружения. Это история проверки исходной связки, а не количество тестов данного публичного репозитория. Физическая приёмка — отдельный этап.

Изменение контракта#

Изменение методов, схем, денежных единиц, правил повторов или результата завершения требует пересмотра API.md и новой фиксации совместимости. Контрольные суммы не обновляются автоматически при обычной сборке: сначала проверяется изменение поведения. Совместимость с backend и оболочкой подтверждается владельцем платформы; статическая проверка этого репозитория не заменяет её.
