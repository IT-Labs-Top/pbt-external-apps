Создайте приложение для фотобудки#

Внешнее приложение — ваш интерфейс и сценарий услуги. Вы выбираете последовательность съёмки, оплаты, обработки и выдачи, а фотобудка выполняет операции с оборудованием через ограниченный SDK.

Как устроена система#

Название Что это означает
Панель администратора Веб-интерфейс централизованного управления фотобудками: установка приложений, настройка услуг, цен, разрешений и просмотр результатов работы.
Сервер панели администратора Серверная часть этой системы. Программа фотобудки получает с неё настройки и передаёт на неё данные; сервер также предоставляет ссылки для скачивания фотографий. Веб-страница панели не должна быть открыта для такого обмена.
Фотобудка Устройство, которым пользуется посетитель: камера, платёжное оборудование, принтер и установленная программа.
Программа фотобудки Установленное на устройстве приложение, которое показывает интерфейс, запускает внешние приложения и управляет их работой.
Локальный сервер Компонент программы фотобудки, работающий на том же устройстве: принимает команды SDK, взаимодействует с оборудованием и учитывает операции.
Внешнее приложение Ваш статический сайт с интерфейсом и сценарием услуги, который запускается в программе фотобудки.
Услуга Доступный посетителю сценарий с заданными в панели администратора ценой, приложением и разрешениями.
Сессия и запуск Сессия описывает работу с одним посетителем (sessionId), запуск — выполнение внешнего приложения в этой сессии (runId).

SDK — JavaScript-клиент API внешних приложений. Термин origin в сетевых настройках означает схему, домен или IP-адрес и порт, например https://api.example.com:9443.

Подключите SDK#

Для первого запуска без оборудования откройте песочницу: node sandbox/start.mjs из корня скачанного репозитория. В ней можно вызвать методы SDK и задать результаты оплаты, камеры и печати. Свою готовую web-сборку передавайте через --app=....

Для обычного HTML положите sdk.js в папку сайта:

import { ExternalClient } from './sdk.js';

const client = new ExternalClient();
const context = await client.context();
await client.ready();

document.querySelector('#price').textContent = `${context.price} ₽`;

Для проекта с npm установите локальный пакет sdk/ из скачанного репозитория. Импорт: @pbt/sdk/external. Адрес API фотобудки и авторизацию вручную задавать не нужно.

Приложение запускается внутри программы фотобудки как установленный статический пакет. Сборка React/Vue также должна содержать готовые HTML/CSS/JS, без зависимости от dev-server. Устройство предоставляет только права, объявленные в манифесте и разрешённые в настройках услуги.

Соберите сценарий#

Вызовите ready() после загрузки интерфейса. Далее связывайте действия с кнопками и показывайте посетителю ожидание и ошибки:

// Пример последовательности; экран и обработчики кнопок определяет приложение.
if (context.price > 0) await client.payment(context.price);
const photo = await client.capture();
await client.print(photo.photoId, 1);
await client.complete();

Снимки можно обработать в Canvas и сохранить JPEG через upload(). Для цифровой выдачи вызовите share() с окончательным списком фотографий и покажите QR до завершения сессии. Все методы и результаты.

Основные правила#

  • Деньги в SDK — рубли: 235.67 означает 235 ₽ 67 коп.
  • Таймаут ожидания не отменяет платёж или печать.
  • Повтор неизвестного результата использует прежние requestId и аргументы.
  • Если известен operationId или jobId, продолжайте ожидание через waitPayment() или waitPrint().
  • При pause остановите ввод, отсчёт и предпросмотр; при stop освободите ресурсы.
  • Принятие запроса возврата не подтверждает возврат банком.

Подготовьте пакет#

Положите service.json и готовые файлы сайта в корень ZIP. Укажите только необходимые разрешения и разрешённые сетевые origin. Формат пакета и передача администратору фотобудки.
