# Версии и совместимость

| Компонент | Версия контракта |
|---|---|
| Runtime API | 1 |
| Манифест | schema_version: 1 |
| Совместимость SDK в манифесте | sdk: "1" |
| Пакет @pbt/sdk | 0.1.0 |

На точке нужны backend и оболочка с поддержкой описанных методов SDK. Контракт соответствует проверенной связке платформы 0.2.38; разные сборки с одинаковым номером могут включать разные дополнения, поэтому совместимость конкретной точки проверяет оператор платформы.

## Форматы данных

[API.md](API.md) описывает методы, ошибки, единицы денег и правила повторов. [openapi.json](openapi.json) содержит маршруты и типы runtime API; [service.schema.json](service.schema.json) — манифест. Готовый SDK поставляется вместе с TypeScript-декларациями.

Контрольные суммы файлов и версии находятся в [compatibility.json](compatibility.json). Обычному приложению не нужно читать этот файл во время работы: он помогает сверить комплект при передаче и разборе несовместимости.

## Обновление приложения

При обновлении SDK пересоберите сайт, повысьте версию в `service.json` и передайте новый ZIP оператору. Не заменяйте байты уже опубликованной версии. Пакет приложения не обновляет backend и оболочку точки.

После обновления снова проверьте свою последовательность оплаты, съёмки, печати и цифровой выдачи. Суммы runtime API — рубли. Для повторов сохраняйте идентификаторы операций; не воспроизводите денежные или физические команды автоматически после перезапуска.
