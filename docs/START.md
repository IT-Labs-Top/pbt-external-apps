# Создайте приложение для фотобудки

Внешнее приложение — ваш интерфейс и сценарий услуги. Вы выбираете последовательность съёмки, оплаты, обработки и выдачи, а фотобудка выполняет операции с оборудованием через ограниченный SDK.

## Подключите SDK

Для обычного HTML положите [sdk.js](downloads/sdk.js) в папку сайта:

```javascript
import { ExternalClient } from './sdk.js';

const client = new ExternalClient();
const context = await client.context();
await client.ready();

document.querySelector('#price').textContent = `${context.price} ₽`;
```

Для проекта с npm установите локальный пакет `sdk/` из скачанного репозитория. Импорт: `@pbt/sdk/external`. Адрес платформы и авторизацию вручную задавать не нужно.

Приложение запускается внутри оболочки фотобудки как установленный статический пакет. Сборка React/Vue также должна содержать готовые HTML/CSS/JS, без зависимости от dev-server. Устройство предоставляет только права, объявленные в манифесте и разрешённые назначением услуги.

## Соберите сценарий

Вызовите `ready()` после загрузки интерфейса. Далее связывайте действия с кнопками и показывайте посетителю ожидание и ошибки:

```javascript
// Пример последовательности; экран и обработчики кнопок определяет приложение.
if (context.price > 0) await client.payment(context.price);
const photo = await client.capture();
await client.print(photo.photoId, 1);
await client.complete();
```

Снимки можно обработать в Canvas и сохранить JPEG через `upload()`. Для цифровой выдачи вызовите `share()` с окончательным списком фотографий и покажите QR до завершения сессии. [Все методы и результаты](API.md).

## Основные правила

- Деньги в SDK — рубли: `235.67` означает 235 ₽ 67 коп.
- Таймаут ожидания не отменяет платёж или печать.
- Повтор неизвестного результата использует прежние `requestId` и аргументы.
- Если известен `operationId` или `jobId`, продолжайте ожидание через `waitPayment()` или `waitPrint()`.
- При `pause` остановите ввод, отсчёт и превью; при `stop` освободите ресурсы.
- Принятие запроса возврата не подтверждает возврат банком.
