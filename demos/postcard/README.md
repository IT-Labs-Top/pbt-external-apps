# Фотооткрытка

Самостоятельный пример на обычном JavaScript, HTML и CSS. Никаких фреймворков, CDN или сборщика для запуска. В `vendor/sdk.js` лежит готовый публичный SDK; приложение работает через тот же API, что и на фотобудке.

Из корня репозитория:

```sh
node sandbox/start.mjs --app=demos/postcard
```

Или `npm run demo`. Нужен Node.js 24+. Откройте адрес из терминала и начните сессию в панели песочницы.

## Сценарий

Цена из настроек услуги → оплата → предпросмотр и снимок → рамка, оттенок и подпись → доплата за дополнительные листы → загрузка готового JPEG → печать → ссылка и QR → завершение.

При `fulfillment=digital` шаг печати и доплата пропускаются. Цена `0` пропускает начальную оплату. Погода необязательна и по умолчанию отключена.

## Где менять код

| Файл | Назначение |
|---|---|
| `index.html`, `style.css` | Экраны, тексты и внешний вид. |
| `src/app.js` | Последовательность экранов, вызовы SDK, пауза и остановка. |
| `src/operations.js` | Сохранение ID, неизменных аргументов и результатов операции. |
| `src/postcard.js` | Canvas 1200×1800, обрезка фото без искажения, эффект, подпись и рамка. |
| `src/weather.js` | Необязательный запрос к объявленному в манифесте внешнему API. |
| `service.json` | ID, версия, разрешения и разрешённая сеть. |
| `vendor/sdk.js` | Неизменённый SDK. Его не нужно адаптировать под песочницу. |
| `package.mjs` | Сборка ZIP этого примера средствами Node.js, без зависимостей. |

Рамки и эффекты берутся из каталога SDK. Пример использует рамки для одного портретного изображения, без схем фотополосок. Если подходящей рамки нет, доступна базовая открытка. CSS-эффект применяется к фото и сохраняется в JPEG, а не только показывается в интерфейсе.

## Настройки config

В панели песочницы можно задать:

```json
{
  "city": "Самара",
  "weather": {
    "enabled": false,
    "latitude": 53.1959,
    "longitude": 50.1008
  }
}
```

При включении погоды выполняется один запрос к `https://api.open-meteo.com`; его origin объявлен в `service.json`. Используются заданные координаты города, геолокация посетителя не запрашивается. Таймаут или отказ сервиса не мешает созданию открытки. Данные погоды фиксируются вместе с оформлением до загрузки JPEG.

Данные [Open-Meteo](https://open-meteo.com/) требуют атрибуции CC BY 4.0; она присутствует в интерфейсе и на открытке с погодой. Бесплатный endpoint предназначен для некоммерческого использования; для коммерческого развёртывания выберите подходящие условия поставщика и обновите код/манифест. Ключи и другие секреты нельзя помещать в публичный `config` или код веб-приложения.

Для проверки неопределённых результатов можно задать `timeouts.commandMs`, `timeouts.paymentMs`, `timeouts.printMs` от 100 до 600000 мс. По умолчанию — 15000, 600000 и 600000 мс. Уменьшение времени ожидания не отменяет принятую операцию.

## Ошибки и повторы

После таймаута повтор использует прежние ID, аргументы и JPEG. Для известной оплаты/печати продолжается ожидание по `operationId`/`jobId`. После частичного внесения денег новая оплата автоматически не создаётся. Подтверждённая частичная печать требует помощи администратора и не запускает повторное задание.

Перезагрузка страницы начатой сессии блокирует новый сценарий и показывает экран сверки. Этот простой пример не восстанавливает Canvas и очередь действий после перезагрузки: операции нужно проверить с администратором, затем завершить старую сессию. Кнопка начала новой сессии в песочнице создаёт отдельный запуск.

При недоступности цифровой выдачи после успешной печати повторяется только подготовка ссылки. QR показывается до завершения сессии. В локальной песочнице он ведёт на галерею этого компьютера; скачивание на телефон проверяется с сервером панели администратора.

Пауза блокирует ввод и останавливает предпросмотр и отсчёт. Уже принятые операции могут закончиться во время паузы; следующий шаг ждёт продолжения. При остановке освобождаются таймеры, запрос погоды и ресурсы страницы.

В «Помощи» доступен запрос проверки возврата внесённых денег. Он закрывает запуск и передаёт решение программе фотобудки; приложение не объявляет банковский возврат успешным по одному подтверждению приёма запроса.

Вызовы `stage`, `track`, `logError` связывают ошибки с операциями. Текст подписи и содержимое фото не записываются в события. Для поддержки скачайте диагностику из панели песочницы.

## Собрать свой ZIP

Меняйте файлы проекта, затем увеличьте `version` в `service.json`. Для своего приложения также задайте собственные `id` и `name`.

```sh
node demos/postcard/package.mjs
```

Из папки примера можно выполнить `node package.mjs` или `npm run package`. Получатся ZIP в `dist/`, SHA-256 и `package-info.json` с хешами готовых файлов. Архив содержит манифест, HTML/CSS/JS, SDK и SVG прямо в корне, без дополнительной папки. Тесты, README и инструмент упаковки в него не входят. Переводы строк нормализуются в LF, время ZIP фиксировано для воспроизводимости.

Уже собранная версия с другими файлами не перезаписывается: сначала увеличьте версию манифеста. Если добавляете собственные файлы или меняете entry, обновите список файлов/проверку в `package.mjs`. Это упаковщик конкретного примера, не общий валидатор сторонних пакетов.
